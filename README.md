# k9s plugins

An unofficial collection of k9s plugins. Install each plugin separately using its documentation. Snippets live in [`plugins/`](plugins/), with any helper commands in [`bin/`](bin/).

## Plugins

| Plugin | Shortcut | Purpose |
| --- | --- | --- |
| [Copy workload view](docs/copy-workload-view.md) | `Ctrl-Y` | Copy a best-effort `kubectl` command for the selected workload and its related resources. |
