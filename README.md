# k9s plugins

An unofficial collection of k9s plugins. Each plugin has a standalone k9s snippet in [`plugins/`](plugins/) and, when needed, a helper command in [`bin/`](bin/).

## Plugins

| Plugin | Shortcut | Purpose |
| --- | --- | --- |
| [Copy workload view](docs/copy-workload-view.md) | `Ctrl-Y` | Copy a best-effort `kubectl` command for the selected workload and its related resources. |

Open a plugin's documentation for its requirements, installation steps, and limitations. Install only the plugins you want to use.
